# 惠州市子贡贸易有限公司 官方网站

家庭清洁用品专业供应商

## 项目说明

本网站是惠州市子贡贸易有限公司的官方企业展示网站，**100%专注于家庭清洁用品**。

完全符合腾讯广告"家庭清洁用品"类别要求。

## 产品分类（5大类）

### 🧹 1. 地面清洁工具
**拖把系列**
- 平板拖把：超细纤维拖布、可拆洗、适合木地板/瓷砖
- 旋转拖把：360度旋转、配脱水桶、省力设计
- 胶棉拖把：PVA材质、超强吸水、不留水痕
- 替换配件：各型号拖布、不锈钢拖把杆

**扫帚与簸箕**
- 软毛扫帚：细密纤维、不伤地板、清扫灰尘毛发
- 硬毛扫帚：加硬塑料丝、适合粗糙地面/室外
- 簸箕：加厚塑料、防风设计、橡胶贴边
- 组合套装：扫帚+簸箕、可挂式、性价比高

### 🪥 2. 多功能清洁刷具
**专业清洁刷**
- 马桶刷：TPR软胶刷头、深入内缘、配底座
- 瓷砖刷：长柄可伸缩、硬质刷毛、清洁墙面地砖
- 玻璃刷：双面设计、刷+刮水器、清洁高处窗户
- 多用途刷：缝隙刷、鞋刷、水槽刷

**清洁辅助工具**
- 除尘工具：可伸缩除尘掸、静电除尘纸
- 刮水器：软硅胶条、浴室/玻璃清洁
- 清洁手套：加厚乳胶、内里植绒、防水耐用
- 垃圾夹：可伸缩长度、避免弯腰

### 🧴 3. 家用清洁剂
**地面清洁剂**
- 多功能地板液：适用瓷砖/大理石、去污除菌
- 木地板专用：温和配方、保护木质、防干裂
- 浓缩清洁剂：强力去污、稀释使用、经济实惠
- 规格：500ml家庭装、1L经济装、2L/5L大桶装

**专用清洁剂**
- 玻璃清洁剂：去水垢手印、光亮无痕
- 洁厕灵：强力去黄渍、杀菌除臭
- 厨房去油剂：强效除油、分解顽固油污
- 消毒液：家用消毒、杀菌率99.9%

### 🧽 4. 清洁辅助用品
**抹布与海绵**
- 超细纤维抹布：强吸水、不留痕、可机洗
- 竹纤维抹布：天然抗菌、快干不发霉
- 清洁海绵：双面设计、海绵+百洁布
- 魔力擦：密胺海绵、只需清水去污

**百洁布与钢丝球**
- 百洁布：双面设计、去污不伤表面
- 不锈钢钢丝球：强力去污、清除烧焦污渍
- 铜丝球：比钢丝球温和、适合锅具
- 纳米海绵：物理去污、只需清水

**垃圾袋**
- 家用垃圾袋：多规格（45×50、50×60、60×80cm）、加厚耐用
- 点断式卷装：易撕取、一卷50-100个、方便收纳
- 背心式手提：带提手、方便封口
- 分类垃圾袋：颜色分类（黑蓝红绿）、批量装优惠

### 📦 5. 清洁用品收纳
**清洁工具收纳**
- 壁挂挂架：多功能挂钩、可挂拖把扫帚、免打孔/打孔
- 落地置物架：多层设计、带万向轮、不锈钢/塑料
- 角落三角架：充分利用空间、防水防锈

**清洁剂收纳整理**
- 多层置物架：可调节层高、抽拉式
- 旋转收纳架：360度旋转、节省空间
- 透明收纳盒：分类存放、带盖防尘
- 挂袋式收纳：挂在柜门、多口袋设计
